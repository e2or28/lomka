# Анимации комнаты барона и игры

**Цель:** выполнить утверждённые анимации; каждый коммит содержит ровно две законченные анимации с проверками и документацией.
**Архитектура:** отдельные модули представления, исходные спрайты сохранены. Фазы атак читаются из симуляции; косметические переходы отслеживаются локально и сбрасываются при смене комнаты/забега. Урон, движение, ввод и формат сейва не меняются.
**Проверка:** свойства опор и фаз в headless, tools/check.sh перед коммитом, контрольные рендеры реального WorldView.

- [x] 01. Цикл качалки + подготовка/выпуск залпа.
- [x] 02. Ожидание барона с флагами + реакция барона на попадание.
- [x] 03. Остановка и смерть барона + полёт нефтяной капли.
- [x] 04. Нефтяной всплеск + полный удар ICE.
- [x] 05. Ходьба охраны + прицеливание/выстрел солдат.
- [x] 06. Характерная ходьба обычных врагов + гусеницы Тандема.
- [x] 07. Ходьба героя вниз + ходьба героя вверх.
- [x] 08. Извлечение органа + установка органа.
- [x] 09. Раненый игрок + помощь/подъём товарища.
- [x] 10. Постановка чемодана + попадания/разрушение чемодана.
- [ ] 11. Выпадение/подбор лута + смена оружия.
- [ ] 12. Уничтожение Тандема + открытие проходов.
- [ ] 13. Мерцание лампы + пыль от работы качалки.

Для каждой пары: реализовать поведение и необходимые слои, проверить соответствие моментам симуляции и сбросу состояния, просмотреть контрольные фазы, выполнить проверки, включить только эту пару в коммит. Новые кадры вертикальной ходьбы готовятся отдельно; общий WorldView интегрируется последовательно.
