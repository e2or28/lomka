# Кооператив и боевые комнаты

> Исполнение: subagent-driven-development для отдельной задачи симуляции, затем проверка интеграции.

**Цель:** отдельные спрайты трёх обычных врагов, разнообразное воспроизводимое наполнение комнат, подъём товарища и рабочее лобби на 1–4 игроков.

**Архитектура:** хост выполняет SimTick, клиенты передают только команды своего слота. Состояние и события передаются клиентам; собственное движение предсказывается с последующей сверкой. Существующий локальный стенд остаётся доступен. ENet даёт прямое подключение без Steam App ID. Приглашения Steam не входят в проверяемый результат этой версии.

## Симуляция

- [x] `sim/revive.gd`, `sim/player_slot.gd`, `sim/tick.gd`: E рядом с упавшим на протяжении 300 тиков, остановка движения и огня, отмена при отходе/отпускании, восстановление 30% HP и короткая неуязвимость. Один спасатель на цель, без удвоения скорости. UI прогресса в `game/organ_hud.gd`.
- [x] `sim/room_travel.gd`, отдельный модуль встреч: воспроизводимые по сиду составы и точки появления, безопасные расстояния, телеграф подкреплений, масштаб 1–4 игрока. Приёмная безопасна, Тандем остаётся один. Повторный вход не создаёт врагов заново. Все отложенные появления сериализуются и блокируют зачистку.
- [x] Тесты настоящих тиков: отмена и успешный подъём, сейв посреди подъёма, разные/одинаковые сиды, безопасность появления, отсутствие повторного спавна после возвращения и сохранения.

## Сеть и лобби

- [x] `game/network_session.gd`: создать/подключиться, список участников, готовность, запуск хостом, отказ при полной комнате/несовместимой версии, корректный выход и потеря хоста. Назначение слотов только хостом.
- [x] `game/lobby_panel.gd`: открыть лобби из стенда, имя, адрес, создать, подключиться, готовность, начать, выйти; сообщения об ошибках на русском.
- [x] `game/dev_sandbox.gd`: локальный режим прежний; по сети хост считает мир, клиент отправляет свой ввод и отображает полученное состояние. Отладочные изменения мира запрещены клиенту.
- [x] `game/network_prediction.gd`: предсказание только собственного движения, подтверждение последовательности ввода и повтор непринятых команд поверх состояния хоста.
- [x] Проверить несколько настоящих сетевых процессов, движение каждого слота, переходы, отказ пятому игроку, отключения, сверку состояния и ограничение чужих команд.

## Результат проверки 10 сентября

`tools/check.sh`: 38 файлов, 1250 проверок, синтаксис и запуск сцены без ошибок.
`python3 tools/test_network.py`: четыре настоящих экземпляра полной игровой сцены и два пробных клиента; ready/start, свои слоты, одинаковые авторитетные снимки, подъём за 300 тиков, переход с врагами/волной, отказы по версии/заполнению, рестарт, выход и принудительная потеря ведущего прошли.
Проверены PNG игрового экрана, лобби и зон попадания; девять WAV имеют корректную длительность, формат и запас до перегруза.
Внешний NAT, два физических компьютера и качество управления при потерях пакетов остаются отдельной проверкой, а не заявленной возможностью этой приёмки.
