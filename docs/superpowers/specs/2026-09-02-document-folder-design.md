# Метательная папка с документами — дизайн ассета

## Назначение

Один прозрачный PNG метательной папки служащего для художественного теста M1. Ассет должен быть пригоден как базовый кадр будущей анимации: папка летит по дуге, делает один прыжок и ровно один полный переворот.

## Внешний вид

- Направление: «переполненное дело» — кривая, распухшая от бумаг папка на завязках.
- Материал: потёртый охристо-коричневый картон, кремовые листы, бордовые завязки.
- Силуэт: горизонтальный, компактный, асимметричный; торчащие листы заметны, но не дробят форму.
- Ракурс: лёгкий вид сверху-сбоку, позволяющий узнавать предмет при вращении.
- Детализация: тёмный контур 1–2 пикселя, мягкий ручной пиксельный шейдинг, без текста и микродеталей.
- Стиль: размер пикселя, палитра и характер контура согласованы с `art/player.png`.

## Технический результат

- Файл: новый PNG с прозрачным фоном, без замены текущей заглушки до визуальной проверки.
- Целевой нативный размер: приблизительно 32×28 пикселей; допустимо немного шире, если этого требует читаемость листов и завязок.
- Вокруг предмета нет тени, свечения, движения, частиц и нарисованного фона.
- Папка целиком помещается в холст и имеет свободный прозрачный край для вращения без обрезания.

## Критерии приёмки

1. На масштабе 1:1 предмет сразу читается как переполненная папка с документами.
2. Он визуально принадлежит тому же миру, что служащий из `art/player.png`.
3. Силуэт не разваливается при уменьшении и остаётся понятным во время вращения.
4. Альфа-канал настоящий; фон и полупрозрачный ореол отсутствуют.
5. Ассет можно использовать как основу будущего спрайт-листа одного прыжка и одного переворота.
