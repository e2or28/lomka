# Метательный портфель для документов — дизайн ассета

## Назначение

Один прозрачный PNG делового портфеля служащего для художественного теста M1. Ассет должен быть пригоден как базовый кадр будущей анимации: портфель летит по дуге, делает один прыжок и ровно один полный переворот.

## Внешний вид

- Направление: классический закрытый деловой портфель, предназначенный именно для документов формата A4.
- Материал: матовая чёрная кожа, графитовые блики, два небольших серебристых замка и верхняя ручка.
- Силуэт: компактный, вытянутый вниз, с высокой плоской лицевой стенкой и небольшой глубиной; не похож на инструментальный кейс или чемодан.
- Документы: из-под закрытого клапана виден только небольшой чистый белый край бумаги.
- Ракурс: лёгкий вид сверху-сбоку, позволяющий узнавать ручку и замки при вращении.
- Детализация: тёмный контур 1–2 пикселя, мягкий ручной пиксельный шейдинг, без текста и микродеталей.
- Стиль: размер пикселя, палитра и характер контура согласованы с `art/player.png`.

## Технический результат

- Файл: новый PNG с прозрачным фоном, без замены текущей заглушки до визуальной проверки.
- Целевой нативный размер: приблизительно 42×34 пикселя.
- Вокруг предмета нет тени, свечения, движения, частиц и нарисованного фона.
- Портфель целиком помещается в холст и имеет свободный прозрачный край для вращения без обрезания.

## Критерии приёмки

1. На масштабе 1:1 предмет сразу читается как чёрный офисный портфель для бумаг.
2. Он визуально принадлежит тому же миру, что служащий из `art/player.png`.
3. Силуэт не разваливается при уменьшении и остаётся понятным во время вращения.
4. Альфа-канал настоящий; фон и полупрозрачный ореол отсутствуют.
5. Ассет можно использовать как основу будущего спрайт-листа одного прыжка и одного переворота.
