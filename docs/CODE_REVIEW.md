## Папки и процессы

Сохранены границы `sim/`, `game/`, `tests/`, `tools/`, `art/`, `assets/`.
Перемещение этих каталогов не даёт выявленного выигрыша и затрагивает
`res://`-ссылки, генераторы и документацию.

В `tests/tools/` лежат тесты shell-обёрток на стандартном Python с подставным
движком. Они изолированы от GDScript-харнесса и не обращаются к сети.
`tools/check.sh` объединяет их с аудитом синтаксиса, headless-тестами и
проверкой стенда. Pre-commit использует ту же команду; она пригодна и
для будущего CI с установленным GodotSteam через переменную `GODOT`.
Удалены дубли и исправлены устаревшие описания управления и состава тестов.

## Оставшиеся риски

Это отдельные задачи, не исправленные этим набором изменений.

1. **P1, файловый сейв:** `sim/save/save_game.gd`, `save_to_file()` открывает
   целевой файл сразу на перезапись и возвращает `OK` без проверки ошибки
   записи. Сбой во время записи может уничтожить предыдущий сейв. До
   использования настоящих пользовательских сохранений нужны временный
   файл, проверка записи, замена целевого файла и тесты отказов.
2. **P1, наблюдатель Drive:** `tools/watch_art.sh` посылает сигналы по PID
   из файла, не проверяя принадлежность процесса наблюдателю. После
   аварийного завершения и переиспользования PID можно остановить чужой
   процесс; одновременные запуски также конкурируют за общий снимок и
   cleanup. Нужен отдельный пересмотр владения процессом и блокировки.
   В рамках ревью наблюдатель не запускался.
3. **P2, быстрые снаряды:** `_fly_projectiles()` в `sim/tick.gd` проверяет
   пересечение только в конечной точке тика. При достаточно высокой
   скорости цель между началом и концом шага пропускается. До введения
   ускоряющих модификаторов стоит добавить пересечение отрезка с кругом,
   порядок попаданий по расстоянию и регрессии для пробития/стен/дальности.

Повторные `stack.compute()` и поиск цели полным обходом акторов — кандидаты
для профилирования на большой комнате. Кэш пока не добавлялся: `base` и
модификаторы доступны для изменения напрямую, поэтому без изменения
контракта можно получить устаревшие статы и рассинхрон.
