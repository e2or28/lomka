# Окружение

Что установлено на рабочей машине и где лежит. Актуально на 1 сентября 2026.

## Движок

**Godot 4.7.2 в сборке GodotSteam 4.22** — `/Applications/GodotSteam.app`

Это пересобранный движок со Steamworks 1.65 внутри, а не аддон. Аддонной
версии больше нет: GodotSteam слили модуль и GDExtension в одну ветку, и
поставляется теперь только собранный редактор.

```bash
/Applications/GodotSteam.app/Contents/MacOS/Godot --version
# 4.7.2.stable.custom_build
```

Проверка, что Steamworks на месте:

```bash
echo 'extends SceneTree
func _init():
	print(ClassDB.class_exists("Steam"))
	quit()' > /tmp/c.gd
/Applications/GodotSteam.app/Contents/MacOS/Godot --headless --script /tmp/c.gd
# true
```

Universal binary, на Apple Silicon идёт нативно.

**Стоковый Godot** из Homebrew удалён 1 сентября 2026 — в нём нет Steamworks,
и для этого проекта он бесполезен. Если понадобится для сторонних
экспериментов: `brew install --cask godot`.

## Шаблоны экспорта

```
~/Library/Application Support/GodotSteam/export_templates/4.22-g472/
  macos/macos.zip
  win64/  win32/  linux64/  linuxarm64/
```

Это **кастомные шаблоны**: они не кладутся в стандартную папку
`export_templates` движка, а прописываются вручную в поле Custom Template
каждого пресета экспорта. Рядом с каждым шаблоном лежит библиотека Steam API
для своей платформы — её кладут рядом с готовым билдом.

832 МБ. В репозиторий не входят намеренно.

## Арт с Google Drive

Саша выкладывает исходники в папку **«игра саша егор»** на Google Drive.
Она расшарена по ссылке и лежит у Егора в «Доступных мне», а не в своём
диске — по имени её не найти, адресуется по идентификатору из ссылки.
Идентификатор зашит в `tools/pull_art.sh`.

```bash
tools/pull_art.sh          # забрать текущее состояние в art/_inbox/
```

Настройка один раз:

```bash
brew install rclone
rclone config
```

В диалоге: `n` → имя **`lomka`** → storage **`drive`** → `client_id`
и `client_secret` пустые → scope **`2`** → `service_account_file` пустой →
advanced `n` → браузер `y` → Shared Drive `n` → сохранить `y` → `q`.

Два места, где легко промахнуться:

- **Аккаунт в браузере.** Папка расшарена на `faceite2or28@gmail.com`.
  Войдёшь другим — rclone подключится к пустому диску без единой ошибки
- **Дойти до конца.** Пока в терминале не появилось `Got code`, токен
  не записан. Оборванная авторизация оставляет remote без токена, и
  `pull_art.sh` падает с `empty token found`. Лечится
  `rclone config reconnect lomka:`

**Scope 2 — не формальность.** Это ключ только на чтение: ни скрипт, ни
я не можем ничего изменить или удалить в Сашиной папке. Папка не наша,
и цена ошибки там выше цены удобства.

rclone предупреждает, что его общий `client_id` перестанет работать
в течение 2026 года. Когда это случится, лечится своим OAuth-клиентом по
их инструкции `rclone.org/drive/#making-your-own-client-id`: заводится
клиент, `client_id` и `client_secret` вписываются в те два поля, что
оставлены пустыми. Остальной конфиг не трогается.

### Просыпаться на новую заливку

```bash
tools/watch_art.sh 120     # строка на каждый новый или изменившийся файл
```

Скрипт написан не для чтения глазами: каждая его строка будит Клода, и он
сам разбирается, что приехало. Просить его включить слежение надо словами —
**оно живёт только внутри сессии** и умирает вместе с ней. Постоянного
демона нет намеренно: фонового процесса, который переживает перезапуск
и молча жжёт квоту Drive, в проекте быть не должно.

**Наблюдатель на машине один, и побеждает последний запуск.** Включаешь
слежение в новой сессии — прежняя получает строку «перехвачено другой
сессией» и выходит сама. Ничего вручную закрывать не надо.

Один — потому что иначе два Клода разбирали бы одну заливку, каждый со
своей копией снимка, и могли бы одновременно импортировать один набор
и подраться в гите. Последний, а не первый занявший, — потому что сессии
закрывают и открывают по десять раз на дню, и правило «первый держит
замок» означало бы, что слежение навсегда осталось в той вкладке, которую
уже закрыли.

Замок — pid-файл в `$TMPDIR`. Брошенный от убитого насмерть процесса
перезаписывается: живость проверяется по pid, а не по наличию файла.

Посмотреть и остановить руками:

```bash
pgrep -lf watch_art.sh
pkill -f watch_art.sh
```

Опрос, а не подписка. Настоящий вебхук от Google требует публичного
HTTPS-адреса, отдельного ключа с правом записи и продления канала раз
в сутки — всё это ради задержки, которой никто не заметит.

### Куда это едет дальше

Drive — канал доставки, а не источник для игры: там рисунки по два
мегабайта, растянутые до 1536×1024, а стенд читает спрайты в родном
размере.

```
Drive  →  art/_inbox/  →  tools/import_*.py  →  art/*.png
         (мимо гита)      (в родной размер)     (в гите)
```

`art/_inbox/` весит десятки мегабайт, в гит не идёт и сам не чистится —
удаляется когда мешает, `pull_art.sh` вернёт. Что где лежит на Drive и как
принимать перезалитые наборы — `../art/README.md`, раздел «Канал Саши».

## Ограничения машины

MacBook M1, 8 ГБ. Память — узкое место. Godot и тяжёлые приложения
одновременно держать не стоит. Экспорт и запекание — разовые операции,
но память в них улетает.
