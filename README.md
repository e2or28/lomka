# Ломка

Кооперативный рогалик с видом сверху. Закрытый рукотворный мир, случайное
наполнение, органы вместо валюты, полоска ломки вместо голода.

«Ломка» — рабочее кодовое имя, меняется свободно до первой публичной страницы.

## Версия движка

Проект зафиксирован на **Godot 4.7.2 в сборке GodotSteam 4.22**. Это
пересобранный движок со Steamworks внутри — стоковый Godot не подходит,
и шаблоны экспорта нужны тоже от GodotSteam. Подробности в
[docs/SETUP.md](docs/SETUP.md). Патчи (4.7.x) накатываются свободно.
Миноры (4.8+) — только между вехами и только через отдельную ветку: открытие
проекта в новой версии почти необратимо, редактор перезаписывает сцены и
ресурсы в своём формате.
