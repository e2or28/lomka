# Ломка

Кооперативный рогалик с видом сверху. Закрытый рукотворный мир, случайное
наполнение, сборки из органов с бонусами и штрафами, полоска ломки вместо голода.

«Ломка» — рабочее кодовое имя, меняется свободно до первой публичной страницы.

## Коротко

| | |
|---|---|
| Движок | Godot 4.7.2 в сборке GodotSteam 4.22 |
| Рендерер | Forward+ |
| Вид | 2D сверху, стрельба клавишами направления / правым стиком |
| Кооп | Онлайн, 1–4 игрока, авторитетный хост |
| Забег | 20–30 минут, 3–4 зоны |
| Персонажи | 3–4, со своими скиллами |
| Платформы | Windows, Linux/SteamOS (macOS после релиза) |
| Витрина | Steam |
| Старт | 1 сентября 2026 |
| Ориентир релиза | конец августа 2027 |

## Запуск

```bash
tools/run.sh     # стенд разработчика
tools/test.sh    # headless-тесты
tools/check.sh   # все проверки проекта, как перед коммитом
```

Или двойным кликом по «Ломка» на рабочем столе — ярлык собирается
`tools/make_desktop_launcher.sh` и пересобирается после переноса проекта.

Стенд — не игра, а окно в симуляцию: тела слотов ходят от карты ввода,
статы крутятся ползунками, спрайты подхватываются из `art/` по клавише 4.
Клавиши: 1 оверлей, 2 ползунки, 3 сверка масштаба, 4 перечитать `art/`, Tab слот,
Q сменить оружие, R сброс, Esc выход.

В комнате есть мини-босс **Тандем** — танк с предупреждением перед выстрелом.
Убитый курьер даёт сердце (+25% скорости, штраф за остановку дольше 3 секунд),
танк — бронированный позвоночник (+35% урона, −15% скорости). Вместе они дают
«Экспресс-доставку»: +30% скорости снарядов и пробитие дополнительной цели.

**F удерживать 1 секунду** рядом с трупом — извлечь и установить орган.
Движение или стрельба отменяют извлечение. Подсказка заранее показывает эффект
и цену: сердце +10 Heat, позвоночник +25. Убийство само по себе Heat не даёт.
**E** подбирает уже извлечённый орган с пола без Heat; прежний остаётся лежать.
Восемь слотов тела и Heat видны постоянно, описание органа — при наведении.
**V** переключает просмотр тела между игроками локального стенда.

Слот тела один, а органов на него несколько: сердце труса (быстрее рядом
с врагом, медленнее вдали) вытесняет сердце курьера вместе с его сочетанием,
глаз затылочника (выстрел ещё и назад, −20% урона) — глаз нотариуса
(удержать 0,6 с, зато урон ×2). Подсказка перед установкой показывает, что
уйдёт взамен. Сердце труса извлекается из начальника, глаза лежат в архиве.

Восемь предметов лежат по два в приёмной, главном зале, курьерской и архиве:
копирка, резиновая печать, тяжёлая печать, дырокол, красная папка, оптическая
линейка, бегунки, пружина. Берутся на **E**, остаются до конца забега,
одинаковые складываются, рикошет и пробитие достаются каждой стороне залпа.

**Пробел** — «Обеденный перерыв»: чемодан встаёт укрытием перед героем
на 4 секунды, держит 54 урона и задерживает врагов, но всё это время его нет
в руках — стрелять и менять оружие нечем. Перезарядка 10 секунд от установки.

Печень чиновника, глаз снайпера и открытие скрытых комнат сочетанием органов
остаются следующим контентом: деньги, алкоголь и криты ещё не реализованы.
Heat пока не вызывает преследователей.

## Инструменты

```bash
tools/run.sh                 # запустить стенд
tools/test.sh                # headless-тесты симуляции
tools/check.sh               # тесты инструментов, синтаксис, headless, стенд
tools/smoke.sh [кадров]      # дымовой прогон стенда и сквозная проверка ввода
tools/audit_syntax.sh        # аудит на синтаксис Godot 3
tools/gen_project.sh         # пересобрать project.godot и карту ввода
tools/gen_scenes.sh          # пересобрать сцены стенда
tools/gen_fixture.sh         # пересобрать эталонный сейв
tools/install_hooks.sh       # поставить pre-commit хук
python3 tools/gen_road.py    # пересобрать docs/roadmap.svg
```

## Структура

| | |
|---|---|
| `sim/` | симуляция: потоки случайности, стек модификаторов, схемы, тик, сейв. О спрайтах и вводе не знает |
| `game/` | представление: стенд, чтение ввода, отрисовка. Удаляется целиком без последствий для `sim/` |
| `tests/` | headless-тесты плюс эталонный сейв в `fixtures/` |
| `tools/` | генераторы `project.godot` и сцен, скрипты запуска и проверок |
| `art/` | черновые спрайты, читаются мимо импорта движка |
| `assets/` | готовые ассеты игры обычным конвейером Godot |

## Версия движка

Проект зафиксирован на **Godot 4.7.2 в сборке GodotSteam 4.22**. Это
пересобранный движок со Steamworks внутри — стоковый Godot не подходит,
и шаблоны экспорта нужны тоже от GodotSteam. Подробности в
[docs/SETUP.md](docs/SETUP.md). Патчи (4.7.x) накатываются свободно.
Миноры (4.8+) — только между вехами и только через отдельную ветку: открытие
проекта в новой версии почти необратимо, редактор перезаписывает сцены и
ресурсы в своём формате.
