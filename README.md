# Ломка

Кооперативный рогалик с видом сверху. Закрытый рукотворный мир, случайное
наполнение, органы вместо валюты, полоска ломки вместо голода.

«Ломка» — рабочее кодовое имя, меняется свободно до первой публичной страницы.

## Запуск

```bash
tools/run.sh     # стенд разработчика
tools/test.sh    # headless-тесты
```

Стенд — не игра, а окно в симуляцию: тела слотов ходят от карты ввода,
статы крутятся ползунками, спрайты подхватываются из `art/` по F5.
Клавиши: F1 сверка масштаба, F3 оверлей, F5 перечитать `art/`, Tab слот,
R сброс, Esc выход.

## Инструменты

```bash
tools/run.sh                 # запустить стенд
tools/test.sh                # headless-тесты симуляции
tools/smoke.sh [кадров]      # дымовой прогон стенда и сквозная проверка ввода
tools/audit_syntax.sh        # аудит на синтаксис Godot 3
tools/gen_project.sh         # пересобрать project.godot и карту ввода
tools/gen_scenes.sh          # пересобрать сцены стенда
tools/gen_fixture.sh         # пересобрать эталонный сейв
tools/install_hooks.sh       # поставить pre-commit хук
python3 tools/gen_road.py    # пересобрать docs/roadmap.svg
```

## Структура

| | |
|---|---|
| `sim/` | симуляция: потоки случайности, стек модификаторов, схемы, тик, сейв. О спрайтах и вводе не знает |
| `game/` | представление: стенд, чтение ввода, отрисовка. Удаляется целиком без последствий для `sim/` |
| `tests/` | headless-тесты плюс эталонный сейв в `fixtures/` |
| `tools/` | генераторы `project.godot` и сцен, скрипты запуска и проверок |
| `art/` | черновые спрайты, читаются мимо импорта движка |
| `assets/` | готовые ассеты игры обычным конвейером Godot |

## Версия движка

Проект зафиксирован на **Godot 4.7.2 в сборке GodotSteam 4.22**. Это
пересобранный движок со Steamworks внутри — стоковый Godot не подходит,
и шаблоны экспорта нужны тоже от GodotSteam. Подробности в
[docs/SETUP.md](docs/SETUP.md). Патчи (4.7.x) накатываются свободно.
Миноры (4.8+) — только между вехами и только через отдельную ветку: открытие
проекта в новой версии почти необратимо, редактор перезаписывает сцены и
ресурсы в своём формате.
