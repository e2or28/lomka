# tools/ — инструменты, в игру не входящие

Игра о них не знает и работает без них. Правило автономности из
`../docs/LEVEL_EDITOR.md`, пункт второй: **решая задачи для игры, ИИ не
должен забивать себе контекстное окно кодом инструментов.** Поэтому здесь
таблица, а читать сами файлы стоит, только когда правишь именно инструмент.

## Запуск и проверки

| Команда | Что делает |
|---|---|
| `tools/run.sh` | Запустить стенд. Клавиши: F1 масштаб, F3 оверлей, F5 перечитать `art/`, Tab слот, R сброс, Esc выход |
| `tools/test.sh` | Тесты симуляции без окна |
| `tools/smoke.sh [кадров]` | Стенд поднимается и живёт N кадров + сквозная проверка ввода на трёх раскладках |
| `tools/audit_syntax.sh` | Аудит на синтаксис Godot 3 и на `class_name` |
| `tools/install_hooks.sh` | Поставить pre-commit хук |
| `tools/code_stats.sh` | Дашборд по строкам кода на рабочий стол. `--print` — то же в терминал, `--out ПУТЬ` — в другое место |

Обёртки проверяют **сентинел в выводе, а не код возврата**: при ошибке
разбора GDScript движок ругается в stderr и выходит с нулём.

## Генераторы

| Команда | Что пересобирает |
|---|---|
| `tools/gen_project.sh` | `project.godot`: настройки и карта ввода на четверых |
| `tools/gen_scenes.sh` | Сцену стенда |
| `tools/gen_fixture.sh` | Эталонный сейв. **Осознанно**: означает «формат изменился» |
| `python3 tools/gen_road.py` | `docs/roadmap.svg` |

## Арт

| Команда | Что делает |
|---|---|
| `python3 tools/cut_layer.py ВХОД ВЫХОД --auto-neck` | Вырезать часть спрайта в отдельный слой на том же холсте. `--auto-neck` находит шею по самому узкому месту силуэта |
| `python3 tools/make_placeholder_art.py` | Заглушки для спрайтов, которых нет. Существующие файлы не трогает без `--force` |
| `python3 tools/import_sprite.py ВХОД ВЫХОД` | Растянутая картинка → спрайт в нативном разрешении: находит сетку апскейла, вырезает фон, чистит крошку JPEG. `--height N`, `--step S`, `--keep-bg` |
| `python3 tools/make_placeholder_art.py` | Пересобрать заглушки `monster.png` и `folder.png` из пиксельных карт |
| `python3 tools/make_icon.py art/player.png ФАЙЛ` | Квадратная иконка из спрайта |
| `tools/make_desktop_launcher.sh [имя]` | Ярлык на рабочем столе: запуск игры двойным кликом |

Зависимостей нет, кроме `ffmpeg` и `numpy`. Pillow на этой машине не
ставится — системный Python защищён PEP 668, и ломать его ради одной задачи
не стоит.

Карта ввода правится в `input_map.gd`, а не в редакторе Godot: секция
`[input]` пересоздаётся целиком, ручные правки стираются. Забыть пересобрать
не страшно — тест «карта ввода» краснеет на рассинхроне.

## Устройство

Пара «скрипт плюс обёртка»: `gen_project.gd` рядом с `gen_project.sh`.
Общий `godot_env.sh` держит путь к движку и переопределяется переменной
`GODOT`.

Инструменты баланса (автобот, дашборд, редактор таблиц спавна) сюда ещё не
приехали — они начинаются на M1 и описаны в `../docs/LEVEL_EDITOR.md`.
Раньше браться смысла нет: балансировать нечего.
