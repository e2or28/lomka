# tools/ — инструменты, в игру не входящие

Игра о них не знает и работает без них. Правило автономности из
`../docs/LEVEL_EDITOR.md`, пункт второй: **решая задачи для игры, ИИ не
должен забивать себе контекстное окно кодом инструментов.** Поэтому здесь
таблица, а читать сами файлы стоит, только когда правишь именно инструмент.

## Запуск и проверки

| Команда | Что делает |
|---|---|
| `tools/status.sh` | Состояние проекта одной командой: гит, тесты, стенд, объём. С неё начинается сессия |
| `Godot --path . --script res://tools/preview_combat.gd` | Снимок четырёх направлений, снарядов, попаданий и падения: `.cache/combat-preview.png` |
| `Godot --path . --script res://tools/preview_hitboxes.gd` | Зоны урона и напольные круги всех врагов: `.cache/hitbox-preview.png` |
| `Godot --path . --script res://tools/preview_walk.gd` | Все кадры ходьбы и обе стороны: `.cache/walk-preview.png`; `-- --frames` сохраняет 60 кадров для клипа |
| `Godot --path . --script res://tools/preview_tank.gd` | Отдача танка: `.cache/tank-preview.png`; `-- --frames` сохраняет 120 кадров езды, подготовки и выстрела |
| `Godot --path . --script res://tools/preview_arms.gd` | Контрольный снимок рук и оружия: `.cache/arms-preview.png`; нужен запуск с окном |
| `tools/run.sh` | Запустить стенд. Клавиши: 1 оверлей и хитбоксы, 2 ползунки, 3 масштаб, 4 перечитать `art/`, Shift+1..9 спавн монстра, 0 убрать всех, Tab слот, V тело другого игрока, Q оружие, E подобрать, F удерживать для харвеста, R сброс, Esc выход |
| `tools/test.sh` | Тесты симуляции без окна |
| `tools/check.sh` | Все проверки: Python-тесты обёрток, аудит синтаксиса, headless-тесты, стенд. Эту же команду вызывает pre-commit |
| `tools/smoke.sh [кадров]` | Стенд поднимается и живёт N кадров + сквозная проверка ввода на трёх раскладках |
| `tools/audit_syntax.sh` | Аудит на синтаксис Godot 3 и на `class_name` |
| `tools/autobot.sh [--seeds N] [--build ИМЯ]` | Прогон сборок без окна: одна комната, одна стратегия. Таблица по сборкам в терминал, журналы команд и метрики в `data/logs/`. Каждый прогон проверяется повтором из своего журнала |
| `tools/install_hooks.sh` | Поставить pre-commit хук |
| `tools/code_stats.sh` | Дашборд по строкам кода на рабочий стол. `--print` — то же в терминал, `--out ПУТЬ` — в другое место |

Тестовая обёртка проверяет **код возврата, сентинел и ошибки скриптов**:
Godot может напечатать ошибку вложенного вызова, продолжить тест и выйти
с нулём. Ожидаемые `push_error` при отбраковке данных допускаются.
`status.sh` возвращает ненулевой код, если тесты или стенд не прошли.

## Генераторы

| Команда | Что пересобирает |
|---|---|
| `tools/gen_project.sh` | `project.godot`: настройки и карта ввода на четверых |

## Арт

| Команда | Что делает |
|---|---|
| `python3 tools/cut_layer.py ВХОД ВЫХОД --auto-neck` | Вырезать часть спрайта в отдельный слой на том же холсте. `--auto-neck` находит шею по самому узкому месту силуэта |
| `python3 tools/make_placeholder_art.py` | Заглушки для спрайтов, которых нет. Существующие файлы не трогает без `--force` |
| `python3 tools/import_sprite.py ВХОД ВЫХОД` | Растянутая картинка → спрайт в нативном разрешении: находит сетку апскейла, вырезает фон, чистит крошку JPEG. `--height N`, `--step S`, `--keep-bg` |
| `python3 tools/import_room.py ВХОД ВЫХОД --inner X0,Y0,X1,Y1` | Нарисованная комната → фон под игровую зону: пол садится ровно на `Room.bounds`, стены остаются снаружи. Печатает отступ для `WorldView.ROOM_INSET` |
| `tools/pull_art.sh` | Забрать исходники с Google Drive Саши в `art/_inbox/` |
| `tools/watch_art.sh [СЕК]` | Следить за Drive и печатать строку на каждый новый файл. Написан под слежение Клода, не для чтения глазами |
| `python3 tools/import_frames.py ПРЕФИКС ВХОД...` | Набор кадров → общий холст: один рост на весь набор, посадка по полу и центру туловища. `--height N`, `--canvas WxH`, `--root-y N`, `--torso-x N` |
| `python3 tools/make_icon.py art/player.png ФАЙЛ` | Квадратная иконка из спрайта |
| `tools/make_desktop_launcher.sh [имя]` | Ярлык на рабочем столе: запуск игры двойным кликом |

Зависимостей нет, кроме `ffmpeg` и `numpy`. Pillow на этой машине не
ставится — системный Python защищён PEP 668, и ломать его ради одной задачи
не стоит.

Карта ввода правится в `input_map.gd`, а не в редакторе Godot: секция
`[input]` пересоздаётся целиком, ручные правки стираются. Забыть пересобрать
не страшно — тест «карта ввода» краснеет на рассинхроне.

## Устройство

Пара «скрипт плюс обёртка»: `gen_project.gd` рядом с `gen_project.sh`.
Общий `godot_env.sh` держит путь к движку и переопределяется переменной
`GODOT`.

Инструменты баланса (автобот, дашборд, редактор таблиц спавна) сюда ещё не
приехали — они начинаются на M1 и описаны в `../docs/LEVEL_EDITOR.md`.
Раньше браться смысла нет: балансировать нечего.
