# tests/ — проверки без окна

```bash
tools/test.sh     # всё разом, около секунды
```

Симуляция отделена от представления (правило 2 из `../docs/PLAN.md`) в том
числе ради этого: тесты гоняются headless, на каждый коммит, через
pre-commit хук.

**Этот каталог не нужно читать, когда работаешь над игрой.** Достаточно
знать, что здесь лежит и что оно стережёт — таблица ниже. Открывать сами
файлы стоит, только когда правишь тест или разбираешь его падение.

## Что где

| Файл | Что стережёт |
|---|---|
| `test_rng_streams.gd` | Изоляция потоков случайности. **Критерий выхода M0** |
| `test_save_roundtrip.gd` | Круговорот сейва побайтово. **Критерий выхода M0** |
| `test_save_fixture.gd` | Эталонный сейв с диска: молчаливое изменение формата |
| `test_replay_determinism.gd` | Один журнал команд даёт одно состояние. Заготовка под сеть M2 |
| `test_modifier_stack.gd` | Порядок применения модификаторов (правило 4) |
| `test_schema.gd` | Валидатор контента падает на расхождении (правило 5) |
| `test_project_settings.gd` | Рендерер, тик, главная сцена против `DECISIONS.md` |
| `test_input_map.gd` | `project.godot` не разошёлся с таблицей ввода |
| `test_input_deadzone.gd` | Круговая мёртвая зона стика |
| `test_combat.gd` | Стрельба, урон, падение игрока, зачистка комнаты |
| `test_art_library.gd` | Горячая замена спрайтов из `art/` |
| `test_projectile_pose.gd` | Один прыжок, один оборот и тень метательного портфеля |

`framework/test_case.gd` — база, `framework/reference_run.gd` — эталонный
забег для фикстуры, `fixtures/` — эталонный сейв в гите.

## Как написать тест

Файл `test_*.gd`, наследует базу, методы возвращают `true`:

```gdscript
extends "res://tests/framework/test_case.gd"

func title() -> String:
    return "что проверяем"

func _test_свойство() -> bool:
    eq(actual, expected, "что пошло не так")
    return true
```

Список методов харнесс собирает интроспекцией — диспетчер писать не надо.
Про обязательный `return true` и про сторож в `run_all.gd` — раздел
«Ловушки» в `../CLAUDE.md`.

## Два правила

**Тест пишется под названный риск** из `../docs/PLAN.md` или
`../docs/DECISIONS.md`, а не на всякий случай. У каждого файла в таблице
выше такая строчка есть.

**Циклы агрегируются.** Проверка по 48 действиям собирает расхождения в
список и падает один раз, а не сыплет полсотней одинаковых строк.
