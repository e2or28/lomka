# assets/ — готовые ассеты игры

Обычный конвейер Godot: файл кладётся сюда, движок импортирует, код
обращается через `preload`/`load`. Отсюда всё попадает в билд.

Пока пусто: до художественного теста на M1 (`docs/ROADMAP.md`) нечего
класть. Черновики и проверка масштаба идут через `art/` — см. `art/README.md`.
